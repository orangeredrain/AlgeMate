# Algemate：你的线性代数学习伙伴

本项目是基于 C++17 与 Qt 6 开发的桌面端学习工具，旨在避免大型商用数学软件使用门槛高、内存占用大等问题，专为大一学生提供的轻量级、智能化的线性代数学习助手。

本项目是北京大学 2026 年大一下《程序设计实习》课程的大作业，项目报告为 75-report.pdf，演示视频链接为：
