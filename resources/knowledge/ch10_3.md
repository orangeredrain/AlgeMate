# 10.3 酉空间与 Hermite 矩阵

**酉空间**：复线性空间上的**Hermite 内积** $(\cdot,\cdot)$，满足共轭对称 $(\boldsymbol\alpha,\boldsymbol\beta)=\overline{(\boldsymbol\beta,\boldsymbol\alpha)}$，对第一变元线性，正定性。

**标准内积**（$\mathbb{C}^n$）：$(\mathbf{x},\mathbf{y})=\mathbf{x}^*\mathbf{y}=\sum \bar x_i y_i$。

## 讲解提要

**酉矩阵** $U$：$U^*U=I$（$U^*=\bar U^\mathsf{T}$），酉变换保持内积。

**Hermite 矩阵**（自伴）：$A^*=A$；特征值全为实数；可酉对角化 $U^*AU=\Lambda$。

**与实对称**：实对称是 Hermite 的实情形。

**正规矩阵**：$AA^*=A^*A$，可酉对角化（谱定理推广）。

### 例题

$A=\begin{pmatrix}1&i\\-i&1\end{pmatrix}$ 是否为 Hermite？

$A^*=\bar A^\mathsf{T}=A$，是 Hermite，特征值为 $0,2$。

### 思考题

$\mathbb{C}^n$ 中“正交”通常改用什么术语？

### 思考题答案

术语仍仅叫**“正交”**（有时加定语“酉正交 / unitary orthogonal”以示区别），但内积需换成 **Hermite 内积** $(\mathbf{x},\mathbf{y})=\mathbf{x}^*\mathbf{y}=\sum_i\overline{x_i}\,y_i$，“正交”即 $(\boldsymbol\alpha,\boldsymbol\beta)=0$。

相应术语变化：

| 实（$\mathbb{R}^n$） | 复（$\mathbb{C}^n$） |
|---|---|
| 转置 $A^\mathsf{T}$ | 共轭转置 $A^*=\overline{A}^\mathsf{T}$ |
| 对称 $A^\mathsf{T}=A$ | Hermite $A^*=A$ |
| 正交阵 $Q^\mathsf{T}Q=I$ | 酉阵 $U^*U=I$ |
| 正交变换 | 酉变换 |
| 欧几里得空间 | 酉空间 |

三个本质区别：(1) 内积仅对第一变元线性、第二变元**共轭线性**（或反之，看约定）；(2) $(\boldsymbol\alpha,\boldsymbol\alpha)\in\mathbb{R}_{\ge 0}$；(3) 常出现共轭转置 $^*$ 代替转置 $^\mathsf{T}$。
