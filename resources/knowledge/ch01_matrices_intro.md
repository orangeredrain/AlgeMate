# 1.2 矩阵与方程组简介

**矩阵**是按矩形排列的数表；**线性方程组**可用矩阵形式 \(A\mathbf{x}=\mathbf{b}\) 紧凑书写。

## 讲解提要

- 系数矩阵 \(A\)、未知数向量 \(\mathbf{x}\)、常数项向量 \(\mathbf{b}\)。
- 高斯消元对应矩阵的行变换思想（后续章节展开）。

## 例题

写出方程组  
\(x + 2y = 3\)  
\(4x + 5y = 6\)  
的矩阵形式 \(A\mathbf{x}=\mathbf{b}\)，并写出 \(A,\mathbf{x},\mathbf{b}\)。
